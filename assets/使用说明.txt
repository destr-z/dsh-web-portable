========================================
 DSH Web 使用说明
========================================

【一、怎么用】

  1. 把这个文件夹完整解压到任意位置（例如 D:\DSH-Web）
     ※ 请整个文件夹一起解压，不要只复制其中某几个文件

  2. 双击：启动 DSH Web.cmd

  3. 会出现一个黑色窗口，这是正常现象，别关它。
     几秒后浏览器会自动打开界面。
     窗口里也会用方框把界面地址完整打印出来（含 ?token=... 那一长串），
     浏览器没自动打开时，把整行复制到地址栏就能进。

  ★ 用完想退出：关掉那个黑色窗口就行。


【二、第一次必须先做的一件事：填 API Key】

  程序本身不含密钥，需要你自己有一个 DeepSeek 的 API Key。

  打开界面后：
    左下角「设置」→ 找到模型/凭据相关的设置 → 填入你的 API Key → 保存

  没填之前：界面能打开，但发消息不会有回复。


【三、如果 Windows 弹出蓝色警告（很可能遇到）】

  第一次运行会看到「Windows 已保护你的电脑」之类的提示，
  因为程序没有购买数字签名证书。这不是病毒。

  处理办法：
    点提示里的「更多信息」→ 再点「仍要运行」

  每个新版本第一次运行都会遇到，点一次就好。


【四、你的数据存在哪】

  聊天记录、设置、密钥都保存在：

      C:\Users\你的用户名\AppData\Local\DSH-Web

  它和程序文件夹是分开的，所以：

    · 程序文件夹随便改名、移动、覆盖，记录都不会丢
    · 想备份记录：把上面那个 DSH-Web 文件夹整个复制走即可
    · 想彻底清空重来：把上面那个 DSH-Web 文件夹删掉即可

  注意：启动时所在的「工作目录」也是记录归属的一部分（本程序固定用
  数据目录下的 workspace 子目录），所以请始终用本启动器启动，
  不要在别的目录里手动运行那个 exe，否则界面里会看不到原来的对话。


【五、以后怎么升级到新版本】

  1. 关掉正在运行的黑色窗口
  2. 用新版本的程序文件夹，替换掉旧的（路径可以不一样）
  3. 重新双击「启动 DSH Web.cmd」

  记录和设置会自动保留，不用做任何迁移。

  ※ 如果升级后不小心发现界面里"对话不见了"：
     多半是工作目录变了。在界面里打开原来的文件夹即可找回。


【六、关于「插件」文件夹】

  程序文件夹里有一个「插件」文件夹，附加功能（比如「人设」）就放在里面。

  你需要做什么：什么都不用做。每次启动时程序会自动把里面的插件装好。

  想卸载某个插件：
    把「插件」里对应的那个子文件夹删掉，下次启动它就不再生效。

  想添加插件：
    把别人给你的插件文件夹整个复制进「插件」里（里面应该有 package.json），
    下次启动就会装上。

  ※ 一律在关掉程序之后整理这个文件夹，不要在运行中删改。

  ※ 能用的插件必须是"打包好的"形态（带 lib 文件夹、不需要联网下载依赖）。
    从网上下载的源码文件夹通常不能直接放进来用。

  ※ 想看现在装了哪些、「生效/未生效」状态：
    界面左下角「设置」→ 插件列表。

  ※ 本版本自带四个插件。

    ①「人设」—— 给每条对话单独记一个人设：
      · 在「设置」里的「人设」卡片中维护人设模板（可增删改）
      · 在每条对话的输入框上方点「人设」即可给这条对话选定一个人设
      · 没选人设的对话完全不受影响（和没装这个插件一样）

    ②「剧本批注」—— 小说改剧本时，逐集对照原文和剧本、划词写批注：
      · 它只认工作目录下的「剧本工作台」文件夹；没有这个文件夹时，
        界面上会显示一段话，把那段话复制给对话里的 AI，它就会帮你建好。
      · 剧本和清单由 AI 生成，你只负责在界面上划词写批注，
        再点「下发」把这一批批注整理成指令，粘回对话里让 AI 改稿。

    ③「小鲸鱼余额挂件」—— 界面右下角常驻的小鲸鱼，显示 DeepSeek 余额：
      · 填好 API Key（见第二节）后它自己会刷新；点一下鲸鱼可手动刷新
      · 还能看「今日已用」和「每轮对话花了多少」，可拖动吸附到四边、可缩放调音效
      · 这是**第三方开源插件**（MIT，作者 MeteorNOX），不是本程序自己写的
      · 它的本地账本写在数据目录里的 .dshw-usage.json（删了只是丢历史，不影响使用）

    ④「提示词对照」—— 剧本定稿之后，逐集对照**剧本**和**视频提示词**、划词写批注：
      · 它只认工作目录下的「对照工作台」文件夹（里面是 剧本\ 与 v1\提示词、清单、批注）；
        没有这个文件夹时界面上会显示一段话，复制给对话里的 AI 就会帮你建好。
      · 左边是剧本（只读参考），右边是提示词（可以划词写批注）；点提示词的某一块，
        剧本里对应的那几行会高亮 —— 因为清单里记着"这一块来自剧本哪几行"。
      · 用法和「剧本批注」一样：划词 → 写问题 → 点「下发」→ 粘回对话里让 AI 改提示词。

    ※ 插件改动后要**重启本程序**才生效，只刷新浏览器页面是不够的。


【七、端口：本程序默认用 3099】

  之所以不用常见的 3080，是因为开发/调试用的实例常常占着 3080。
  本程序不会去抢别人的端口：如果 3099 已经被别的程序占用，
  它会明确告诉你是谁占的，然后退出，让你自己决定怎么办。

  想换端口，在 cmd 里这样启动（把 3199 换成你要的端口）：

      启动 DSH Web.cmd --port 3199


【八、常见问题】

  Q：黑色窗口一闪就没了？
  A：说明启动出错。双击后仔细看窗口里的红字提示；如果窗口关得太快，
     用 cmd 这样运行，报错就会留在窗口里：

         启动 DSH Web.cmd

     启动器会把程序输出完整写到日志里，位置是：

         C:\Users\你的用户名\AppData\Local\DSH-Web\logs\launcher.log

  Q：提示"端口被别的程序占用"？
  A：按提示里给出的进程名关掉那个程序，或者用 --port 换一个端口
     （见上面第六条）。本程序**不会**自动改用别的端口——盲扫端口会
     先占住别人要用的端口，也可能刚探到空闲又被抢走，反而更难排查。

  Q：浏览器没自动打开？
  A：把黑色窗口里方框内那一整行地址（含 ?token=... ，一个字符都不能少）
     复制到浏览器地址栏。注意这是带登录令牌的地址，不能只访问
     http://127.0.0.1:3099/ —— 那样会提示 authentication required。

  Q：提示 authentication required？
  A：说明打开的是不带令牌的地址，或者换了浏览器/清了 cookie。
     从窗口里复制带 ?token=... 的那一整行重新打开即可。

  Q：提示缺少 deepseek-harness-rg.exe？
  A：压缩包没解压完整，请重新完整解压一次。

  Q：能同时开两个吗？
  A：不用。重复双击只会把已有的界面再打开一次，不会启动第二个。

  Q：能装别的插件吗？
  A：能。把插件文件夹放进程序目录的「插件」文件夹里，重启即可（见第六节）。
     注意只支持"打包好的"插件形态。

  Q：装了插件但界面里没反应？
  A：先看「设置」→ 插件列表里它是不是"已生效"。
     常见原因是插件不带 lib（还没打包）或声明了要联网下载的依赖——
     便携版不联网装依赖，这类插件用不了。
     再确认「插件」里那个文件夹没被改名/挪走。
